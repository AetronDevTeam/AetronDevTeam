| **Fiscal** | NF-e integrada à SEFAZ, eventos, CC-e e importação de XML de compra |
| **Financeiro** | Parcelas, boletos, comissões e despesas |
| **Estoque** | Bobinas, materiais, facas e consumo por pedido |
| **Aetron IA** | Assistente que consulta os dados da operação em linguagem natural |

#### Engenharia

- **Multi-tenant por schema:** cada conta tem um schema isolado no Postgres.
- **Migrações só aditivas:** aplicadas automaticamente em todas as contas, sem perda de dados.
- **Testes:** mais de 1.100 testes automatizados no backend.
- **Fiscal com certificado A1:** assinatura XML e comunicação direta com os webservices da SEFAZ.
- **Edge first:** a landing roda na borda e a IA passa por um gateway com controle de custo.
